# Phishing-awareness-resource
An introduction to phishing and how to identify, avoid and report phishing emails and messages.
## What is this?
A simple guide to help staff and students detect phishing attacks. 
## What is phishing?
Phishing is when someone pretending to be a trusted source/company tries to trick you into clicking on a link, downloading a file or entering your password.
## What's in this repository?
- A guide to detecting phishing (phishing-guide.md)
- A quick checklist to run through before clicking (phishing-checklist.md)
- Examples of real phishing messages (examples.md)
## How to use this. 
Read through the guide, run through the checklist for any suspicious emails and report any phishing to IT.
